# DetoxMate 팀 스킬

Codex·Claude Code가 같은 Notion 기획·정책을 읽고 수정하기 위한 팀 스킬입니다. 개발자와 디자이너 모두 자신의 작업 폴더에서 사용합니다.

## 처음 사용하기

Codex 또는 Claude Code에서 **스킬을 사용할 작업 폴더**를 열고 아래 문장을 붙여 넣으세요. 디자이너는 디자인 작업용 폴더 하나를 만들어 열면 됩니다. Git 저장소일 필요는 없습니다.

```text
https://github.com/DetoxMate/detoxmate-skills/blob/main/INSTALL.md 를 읽고, 지금 작업 폴더에서 쓸 수 있도록 팀 스킬 두 개를 설치해줘. 현재 사용하는 도구에 맞춰 설치하고, Notion 연결도 확인해줘.
```

Python이나 별도 설치 프로그램을 준비할 필요가 없습니다. LLM이 저장소를 받아 현재 작업 폴더에 스킬을 연결합니다. 같은 컴퓨터에서도 FE·BE 등 다른 작업 폴더에서 쓰려면 그 폴더에서 한 번 더 요청하세요.

**Notion 인증은 별도입니다.** 스킬은 `detoxmate-notion` 연결을 사용합니다. 연결이 이미 있으면 LLM이 조회를 확인하고, 없으면 필요한 설정을 안내합니다. 현재 팀원용 CLI·토큰 등록 절차는 별도 준비가 필요합니다. API 토큰을 대화에 붙여 넣지 마세요.

## 사용하기

설치 후 새 대화를 시작합니다. Codex에서는 `$fetch-notion-wiki`, Claude Code에서는 `/fetch-notion-wiki`로 부릅니다.

| 스킬 | 하는 일 |
|---|---|
| `fetch-notion-wiki` | 필요한 정책만 찾아 읽고 근거 링크를 제시합니다. |
| `update-notion-wiki` | 현재 템플릿을 읽고 합의한 정책과 최신 변경이력을 반영합니다. |

예: “친구 요청 화면을 작업하려고 해. fetch-notion-wiki 스킬로 관련 정책과 미정 사항을 확인해줘.”

문서 수정 후에는 사람이 결과를 읽고 검수합니다. 최신 정책과 문서 형식의 원본은 Notion이며, 이 저장소에는 읽고 쓰는 절차를 관리합니다.

## 업데이트하기

같은 작업 폴더의 LLM에 요청하세요.

```text
https://github.com/DetoxMate/detoxmate-skills/blob/main/INSTALL.md 의 업데이트 절차에 따라 이 폴더의 디톡스메이트 스킬을 최신으로 업데이트해줘.
```

이후 새 대화에서 사용합니다. 다른 팀원의 컴퓨터까지 자동 업데이트되지는 않습니다. Notion 정책·템플릿만 바뀐 경우에는 스킬을 업데이트할 필요가 없습니다.

## 공개 범위

이 저장소는 공개이며, Notion 문서 자체와 API 토큰은 포함하지 않습니다. 스킬을 받는 것만으로 팀 Notion 접근 권한이 생기지는 않습니다.

설치 방법의 기술적 기준과 확인 절차는 [LLM용 설치 안내](INSTALL.md)에 있습니다. 기존 전역 설치는 자동 삭제하지 않으며, 새 설치는 작업 폴더 범위에만 적용합니다.
